# Code of conduct
<!-- SPDX-FileCopyrightText: 2026 Hasan Melih Akbulut -->
<!-- SPDX-License-Identifier: CC-BY-4.0 -->

Use respectful, specific technical discussion in issues, pull requests and
project channels. Welcome questions and corrections, distinguish evidence from
assumptions, and criticize work without attacking the person who did it.

Harassment, threats, discriminatory insults, disclosure of someone else's
private information and repeated disruptive behavior are not acceptable.
Maintainers may edit or remove harmful content, close disruptive discussions
or restrict participation, explaining the reason when doing so would not expose
private information. These expectations apply to maintainers as well.

Use GitHub's reporting controls for abusive content. To request confidential
contact with the repository owner, open an issue with only that request; do not
publish names, private messages or other sensitive evidence in the request.
Security vulnerabilities have a separate private route in [SECURITY.md](SECURITY.md).
