This directory preserves source-bound development measurements and native
captures, including physical failures. Project Python methods are Apache-2.0,
project circuit descriptions CERN-OHL-W-2.0, and reports CC-BY-4.0. Generated
IHP geometry retains the upstream PDK attribution (Apache-2.0).

The headroom capsule includes unchanged selected IHP compact-model sources,
including CMC R3_CMC/PSP sources under ECL-2.0. Their original notices remain
inside the capsule; the complete ECL-2.0 text is in /LICENSES/ECL-2.0.txt in
this repository. The inner inherited startup NOTICES text is incomplete on
that model attribution; this explicit additional notice corrects it without
changing the frozen native capture bytes. Selected ngspice diagnostic sources
retain their original BSD-3-Clause notices. No simulator executable or compiled
OSDI binary is included in these compact captures.

Divider, capacitance, fanout and axis-control captures contain original project
methods/circuits, generated geometry/netlists and native observations; tool and
PDK implementations are pinned rather than redistributed in those capsules.
Public full-wave archives contain measurements, with exact byte sizes and
authenticated/anonymous download hashes in the release receipts. A completed
screen is not PLL/CDR, full-PVT, jitter/BER, ESD, full RC or fabrication approval.
