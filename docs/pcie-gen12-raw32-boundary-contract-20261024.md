# Gen1/2 raw32 receive symbol boundary

The recovered-PMA contract supplies 32 consecutive raw bits per valid receive clock, with bit 0 earliest on the wire. The new block removes a caller-selected polarity inversion and searches for complete K28.5 (COM) across every word offset. In wire-first numeric representation, the two COM values are 0x17c (incoming negative RD) and 0x283 (incoming positive RD). The first complete COM establishes a symbol phase and supplies its incoming RD. Four packed slots carry zero through four full 10-bit symbols; slot 0 is earliest. Unused slots are zero. Every raw code, including invalid codes, is preserved after alignment for the independent decoder to classify.

A valid gap contributes no bits and holds the partial stream. A disabled cycle, asserted force_realign, changed polarity or reset discards all buffered bits and flushes the boundary. Control-change cycles discard their current word. Electrical idle, rate changes, bit slips and actual PMA discontinuities must be converted to explicit flush requests by the eventual rate/training owner; raw_valid alone is a word-valid strobe, not continuity detection. The block does not auto-infer polarity from COM because the two encodings are complements. It does not declare LTSSM state, link-up, error recovery or code validity. After acquisition, alignment is fixed until the owner requests a flush; no arbitrary symbol pattern may silently shift it.

The missing integration still requires the explicit-RD decoder chain, Gen1/2 training parser/generator, training/rate owner, elastic/deskew handling and actual low-rate PMA clocks. The current 8 GT/s analog work does not qualify 2.5/5 GT/s operation. With this raw width those rates require 78.125/156.25 MHz word clocks. Existing Gen3 raw-word logic remains unchanged.

Source context: [IEEE 802.3z 8b/10b code table](https://www.ieee802.org/3/z/public/presentations/sep1996/RT8b10b_codes.pdf), independently pinned by the codec branch; [Intel PIPE 7.1](https://cdrdv2-public.intel.com/643108/643108_PIPE_Arch_Spec_Rev_7_1.pdf), original versus raw SerDes ownership and error/polarity interfaces. This block is an implementation-specific raw-PMA seam, not a claim to implement the entire PIPE interface.

Cloud proof uses an independent global serial-bit indexing oracle: all 64 acquisition offsets across two words, both explicit polarities and COM disparities, all 1024 subsequent raw symbols, deterministic valid gaps, no-COM streams, and each flush control at multiple partial-word phases. Ten compiling behavioral mutations must fail the same oracle. Actual Icarus execution and Yosys synthesis run only in GitHub Actions; success or rejection is retained in Releases. Native proof and peer review are required before importing the block into the root integration branch.
