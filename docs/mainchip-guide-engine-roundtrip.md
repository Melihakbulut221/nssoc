The successful engine build 41493369685 is not routing acceptance. This experiment uses its exact ELF in a separate /work/guide-engine/openroad path and retains the original frozen engine, source guards, owned container, dependency fingerprints, supervision, termination and publication controls.

Both complete cloud capsules are authenticated before extracting the selected files: the new engine and the restored iteration19 reference from 41440285882. Every archived member is hashed, including unselected members. Unknown paths, aliases, links, duplicate members, missing entries and changed bytes are refused. Native inputs and outputs stay in GitHub.

The new executable must reproduce the entire old native snapshot and DEF, then write/reload the actual ODB and reproduce them again: 143,820 nets, 154,480 instances, 1,691 protected clock records, all terminal identities, wire opcodes, geometry, master pins and immutable material. The unmodified original full DRT/antenna Tcl runs next; complete measured results and the post-check full snapshot must equal the old engine's reference. Differences are preserved as failures, never silently normalized.

The eight original source-control suites run unchanged, followed by the new hostile-capsule and executable-binding controls. Native dispatch requires a separate successful run at the identical source SHA and an externally reserved release. All failures, native artifacts and derived records are preserved.

This performs zero route or antenna-repair calls. Passing proves no-route engine compatibility on this actual chip, not reduced routing memory, routing convergence, LVS, PHY, final setup/hold or production approval. The next required operation is the full original routing schedule with this qualified executable; the original violations remain open until measured otherwise.
