# Original zero-source initialization diagnostic

The original241-device run40093613768 remains rejected for NaN-temperature and dynamic-gmin diagnostics even though its retained complete waveforms and all-zero OP are readable. This separate experiment runs only the original zero-source operating point, for both P and N variants, with default VBIC OFF=0 versus uniformly OFF=1 on every106HBT. It removes all transient commands, uses no .ic, UIC or nodeset, and never selects a differential phase.

The alter/show command syntax is pinned to the existing repository fixture `scripts/pcie_pll_native_fixture_v1.py`; every actual native flag is read back. The [upstream VBIC implementation](https://github.com/ngspice/ngspice/blob/master/src/spicelib/devices/vbic/vbicload.c) uses a Vcrit junction guess for OFF=0 and zero junction guesses for OFF initialization (inspected blob0a3f7ee5cefed641a8ae88b37b0fe8f27100fb32). The [IHP HBT model](https://github.com/IHP-GmbH/IHP-Open-PDK/blob/main/ihp-sg13g2/libs.tech/ngspice/models/sg13g2_hbt_mod.lib) instantiates Qnpn13G2 as VBIC (inspected blob2acce342e0a06a3727479c5d4bd6687fc998808d). These upstream descriptions motivate a test; the actual frozen runtime/model bundle and native readback determine the result.

The default control must reproduce NaN/gmin diagnostics; the uniform case must have no diagnostics and must independently pass all355 saved electrical/thermal state checks at zero sources. Missing flags, altered targets, changed values or added transient/initial-condition/parameter commands are rejected. Full logs, OP bytes, exact decks, model hashes and failures are preserved.

Even a passing OP comparison establishes only the initial solve. It does not erase original transient diagnostics, qualify the244-device fast-assert circuit, prove a loaded reset tree, or connect/qualify the PLL. Any subsequent fresh transient must independently retain all original34ns/356-plus-new-columns, fixed-phase, solver, numerical and device-safety gates.
