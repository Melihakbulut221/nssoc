# Mainchip original class counterpart scope

This read-only cloud join follows actual obstacle reduction run 41254369577 at
8511f25d897d03e27a05222f5a731abd13534376. It uses the complete compact 434-marker,
373-endpoint, 946-witness evidence and all 162 other marker records. It does not
fetch or repeat the 689 MB native observer reduction.

The original `fixed_plan` in `mainchip_bulk_postdrt_antenna.py` freezes every
ordinary DEF net outside the mutable set. The original `fixed_overlay` records
each original ROUTED, FIXED, COVER or unwired class. Thus an observed FIXED net
outside the protected manifest is not automatically an originally fixed net.

The two exact derived JSON assets on release 430116200 supply the original
143212-entry class map and insertion plan (608 mutable, 1691 protected nets and
1351 added diodes). Inputs, release identity and complete SHA-256 pins are
recorded in the source config and checked on the runner. The compact evidence is
read from immutable proof commit ff2626d9350a03e91554e0be96a6b21018925719.

Output retains all original endpoint, marker and witness records and their
ordinals and multiplicity. It separately labels original ROUTED to temporary
FIXED observations, original FIXED/COVER, unwired, protected and PG members.
Same-layer positive ordinary-wire observations are listed per distinct temporary
counterpart net; cross-layer pins and boundary-only witnesses remain in the
complete output and do not enter that list. Counts are not physical root causes.

No protected or PG net is released, no layout is changed, no routing or timing
claim is made. Baseline/insertion native identity, exact encoded metadata,
iteration10 mutable routes and a reviewed routing repair remain separate work.
All controls and real classification run on GitHub. Inputs/outputs/failures are
retained in a cloud artifact; complete derived output bytes are also emitted in
authenticated chunk form for continuation. No native data is downloaded locally.

Manual workflow modes: `controls` runs only the synthetic metadata controls;
`classify` requires those same controls before reading the pinned real evidence.
Neither mode runs a CAD tool or issues a native routing command.
