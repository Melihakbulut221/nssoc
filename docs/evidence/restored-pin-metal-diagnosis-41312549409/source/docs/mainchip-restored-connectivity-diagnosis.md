# Restored-route pin-metal diagnostic

The unchanged original wire-only connectivity gate failed 142 of 828 actual routed owners in run41308526628. Diagnostic41311644194 replayed every failed graph exactly. Some pins intersect multiple wire components; a logical pin name alone cannot prove those components connected.

This cloud-only successor re-authenticates the same complete 1726-member derived archive and release index. It retains the original gate and its full replay. A second, explicitly non-accepting graph appends only observed ODB/LEF pin rectangles as conductive rectangles on their actual metal layer. It never joins disjoint rectangles by pin identity or infers cross-layer vias. Positive-area and closed-boundary observations remain separate.

All 13 original controls remain. Ten additional controls cover continuous and split pin geometry, layer separation, edge-only contact, missing access, real gaps, overlapping rectangle chains, unchanged input records, ordering, and invalid pin metal.

The report identifies original wire components sharing one observed physical pin rectangle and records complete appended rectangle origins. It distinguishes remaining true geometric gaps in this observation model from failures explained by pin metal. It does not certify GDS/internal cell continuity, make a layout ECO, alter the original gate, or declare connectivity, DRC, LVS, timing, or PHY acceptance. Validate actual cell GDS/LEF correspondence and all original physical gates before any adoption.

All numerical graph work runs on GitHub. No native archive, layout or waveform is acquired locally. Controls precede authenticated readout. Results and source remain cloud artifacts; the complete original native archive is release430583367.
