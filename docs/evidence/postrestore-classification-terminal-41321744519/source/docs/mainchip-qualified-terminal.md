# Post-restoration physical repair diagnosis

Runs wholly on GitHub. Authenticates all 1749 native capsule members from release 430648315, retains actual native phases and original physical rejection. No CAD execution, geometry edits, waived markers or acceptance changes.

The classifier preserves all marker and antenna row ordinals, full bodies and hashes. It groups category, layer, net owners and co-occurrence components, explicitly distinguishing the original 608 diode owners, 220 counterpart owners, 1691 protected nets, power and outside-scope nets. All non-net marker sources are retained. No net-name normalization or logical connectivity inference occurs. An inspection candidate is not a routing authorization; actual database signal identity, original route class and complete geometry must be confirmed before any next repair.

The original frozen scope validator is copied unchanged from source 340fb4f217e920c1bc4d5fa552e4b11eb81d0a4b. Sixteen classifier controls reject truncated or unknown category data, waived records, invalid geometry, scope overlaps and false antenna rows; duplicate records retain distinct ordinals, protected/power owners remain excluded from inspection candidates. All tests run in the cloud.

The native physical result remains 399 DRC markers, 19 antenna nets and 23 antenna rows. Full serial PHY and final timing remain open. Every native input remains in cloud storage, including the 27 MB all-net table which is authenticated but not copied into bounded derived outputs.
