Exact C10 synthesis source snapshot for an isolated ALU prefix experiment

This archive contains unchanged source and recipe inputs of the 2026-09-27
CORE_REQ_REG=1, CORE_WB_STAGE=1 synthesis that produced the C10 physical
checkpoint. Every synthesis input is bound to the original receipt and the
adjacent hw/soc/pnr/alu-prefix-c10-input.lock.json. It contains no tool binary,
placed/routed design, new synthesized candidate or production approval.
