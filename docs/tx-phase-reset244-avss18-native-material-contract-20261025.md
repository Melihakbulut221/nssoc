# Native AVSS18 material comparison contract

The hosted source controls passed at run 40206328842, source ec29fe6f. This new comparator is source-only and unexecuted. The physical controller, complete restoration and publication integration are still being prepared; this file does not authorize a native job.

`tx_phase_reset244_avss18_native_material.py` reads the exact original P/N GDS, LEF, schematic and generation report after complete archive authentication. It pins original hashes to the 5591fe78 qualified physical result, requires generation-report equality to that result, byte-equal old/new LEF and schematic, actual new GDS hash equality to the candidate generation report, actual KLayout 0.30.7 and the exact frozen 5d2a8f29 layer-properties file. The numeric TopMetal1 layer comes from that hash-checked file, including its optional layout-view suffix; no R-edge type is used as a layer identifier.

Comparison retains every loaded cell name, actual DBU, top cell, bounding box, shape type/record/text semantic field, property type/value, instance target/transform/array dimensions and multiplicity. Layout-local property IDs are not treated as property contents. The sole admissible raw shape-record change is one top-cell box: old source [109,89,115,2371] to new [103,89,121,2371], with exact unchanged [0,-3.97] translation converted through decimal arithmetic to integer DBU. Complete recursive material regions must be equal on every other layer. TopMetal1 must equal the original material union the new rectangle, with no removals or unexpected additions; added unique material excludes any already-present unchanged material. This measures material overlap without inferring net ownership. All native ownership and DRC/LVS gates remain mandatory.

Both actual layouts are read from their saved files. Eighteen refusal cases mutate new candidate layouts only in hosted memory: unchanged old trunk, wrong width/center/y/layer, unrelated top/leaf material, changed non-target box, text string/font, instance transform/array/target/property, shape/cell property, cell name and DBU. Every refusal follows the real positive comparison. A pristine reread repeats the positive comparison after faults; the original and candidate files plus layer map must remain byte-identical. No GDS is written by this comparator. Its full structured result is written before validation and on every exception.

The exact APIs are documented in the primary KLayout [Shape](https://www.klayout.de/doc/code/class_Shape.html), [Instance](https://www.klayout.de/doc/code/class_Instance.html) and [Cell](https://www.klayout.de/doc/code/class_Cell.html) references. Actual API execution and geometry identity remain unproved until the reviewed Ubuntu 22.04/AppImage job runs. Material equality does not establish conductivity/ownership, DRC, LVS, wire/MIM RC, loaded timing or electrical safety. The original electrical rejection remains authoritative.
