## Smallest reviewable implementation unit

Add `hw/soc/rtl/pcie/soc_pcie_training_ingress_x4_v1.v` and `soc_pcie_training_epoch_control_v1.v` as new candidates, retaining qualified modules byte-for-byte. A derived `soc_pcie_gen3_recovered_front_x4_v1.v` should expose the aligner/CDC portion of `soc_pcie_gen3_recovered_x4_v4.v:49–79` with an exact derivation and equivalence test; it must reuse the existing FIFO/reset primitives once. This creates an actual consumer seam, not a second disconnected decoder.

Proposed ingress ports retain independent valid/ready per physical lane. Gen1/2 carries `data[127:0]`, four 16-bit K/code-error/disparity-error/comma vectors. Gen3 carries `block[193:0]`, `length_code[2:0]`, SKP/EIEOS/realign and sticky loss/fault. Keep these typed streams separate; the Gen1/2 wrapper's two padding bits and fixed container code are opaque transport, never Gen3 protocol evidence. Carry an explicit active epoch alongside accepted records. Epoch width, wrap refusal and retained-history bound must be fixed before RTL review.

The common-clock control request should identify epoch, externally selected encoding/rate, per-lane polarity and alignment action. A held request/acknowledgment mailbox must latch one coherent command per recovered domain and report completion/fault back to common clock; it cannot synchronize each bus bit independently. Reset assertion and release must preserve the existing coordinated reset barrier and polarity-settling edge. Rate/PMA readiness is an externally supplied, epoch-matching acknowledgment; the wrapper does not select clocks, detect analog lock or infer a stopped clock. Mid-epoch clock discontinuity still requires the explicit external loss input. No command or stale acknowledgment may release packets while another lane remains in the previous epoch.

Stop admission, abort or explicitly drain the prior owner epoch, coordinate the reset barrier, establish the new externally acknowledged rate/polarity, then admit complete records. A rate request must not relabel queued old records. Normal EIOS/EIEOS end retains accepted packet/events until drain (`soc_pcie_gen3_recovered_events_v2.v:60–93`); an explicit abort has different semantics. The first unit exposes an owner-authorized normal-mode handoff request but cannot authorize it itself. A follow-on version of `soc_pcie_gen3_recovered_owned_rx_v1.v` / `soc_pcie_gen3_recovered_events_v2.v` must consume the same ingress stream rather than run a duplicate raw front end; its TS-to-normal scrambler-state handoff requires a separately sourced protocol contract before implementation.

## Independent proof boundary

Add `hw/soc/tb/cocotb/test_soc_pcie_training_ingress_x4_v1.py`, `test_soc_pcie_training_epoch_control_v1.py` and `scripts/check_pcie_training_ingress_x4.py`. Reuse the pinned Gen1/2 serial/list oracle and Gen3 raw-bit driver, not the DUT's internal classification. Cover all 192/194 fields, variable Gen3 lengths, lane identity, simultaneous pop/full, held output, prefix-before-fault, independent clocks, startup with a stopped clock versus mid-epoch pauses, both reset domains, same-polarity reset, delayed/wrong-epoch PMA and lane acknowledgments, overflow and all fields during a rate change. Require explicit old/new epoch exclusion, no half-record or stale-command admission, and no automatic clock-loss claim.

Keep the exact normal packet tests in `test_soc_pcie_gen3_recovered_events_v2.py` (normal-end drain, held events, abort) and `test_soc_pcie_gen3_recovered_x4_v3.py` (early arm, stopped startup, realign, loss, overflow). Later composed tests must show that COM, SDS, apparent L0 or a transport-ready bit alone cannot emit link-up or release DLLPs, and that raw Gen3 training records remain available to the semantic owner. Compiling mutations must disconnect epoch/ack/reset/field paths and fail explicit public assertions; setup, unknown conversion, timeout supervision and memory failures remain distinct from behavioral detection. No test listed here has been authored or executed.

## Protocol prerequisites still open

The pinned primary-source boundary records the public PCI-SIG FAQ constraints: state-specific Gen3 TS comparison of symbols 6–9, retention of the latest transition's received EQ TS2 preset for repeated phase 0, and inhibition of DLLPs in the described intermediate-L0 equalization sequence. These are necessary partial constraints; the complete target Base 3.0 field/state/timer and applicable errata oracle has not been obtained. This audit reuses that immutable source record and does not claim a fresh full-spec read. The older Gen1/2 reference cannot fill the Gen3 gap.

Full negotiated x4 lane assignment, state-specific TS acceptance, rate/equalization sequencing and timers, TX policies, logical-lane seeds, polarity/RD ownership, PMA control, clock switching, and packet/DLLP release remain the responsibility of the eventual connected owner. No permissive defaults, forced-negative RD at every TS, blanket repeated-byte acceptance rule, or COM/SDS-derived link-up is proposed. All training-owner, LTSSM, PMA and full-PHY acceptance flags remain false.
