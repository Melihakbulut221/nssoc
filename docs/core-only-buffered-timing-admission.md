# Buffered parent extraction and timing admission

Prepared workflow only. Do not dispatch until the route is terminal and its native and summary artifacts have been independently verified. Pin the exact native artifact ID and SHA256 into `cloud_core_only_chip_buffered_timing.py`; both currently default to None and block execution.

The candidate must have zero native routing DRC, exact source/state preservation, exact pad-contact selection proof and complete visible geometry connectivity. The runner then creates a NEW nominal SPEF, verifies capacitance conservation and exact native ODB net/terminal/resistance graph coverage, and loads that SPEF with genuine slow/typical/fast standard-cell and IO models. It preserves the 20 ns internal clocks and 5% derate.

No old SPEF is restored. Core-internal parasitics/model, complete external IO timing, CDC qualification, RC min/max and manufacturing acceptance remain outside this diagnostic's proven scope and remain open product requirements.
