# Complete TX input-driver physical assembly — 16 October 2026

This experiment assembles the original `tx_cmos_hv_resistive_input_v7.inc` circuit: four measured ng10 HV devices, the exact foundry buf16 GDS and four native rppd resistors. Every original signal/source/drain/gate connection and all six external ports are derived from the source, with original widths and finger counts. The HV GDS and buf16 inventory are restored from immutable successful cloud runs, verified by archive, summary and member hashes.

The physical reference adds explicit finite contacts: nine added substrate contacts and one added well contact, plus the two intrinsic buffer ties measured directly from the source GDS. The actual chip substrate is common; NMOS and resistor bodies connect to this substrate node, and PMOS bodies to the contacted buf16 NWell. This physical body mapping is recorded rather than silently treated as the ideal original source/body voltage connection. Substrate spreading and electrical equivalence are **not qualified** by LVS. The original buf16 junction parameters are retained in the aggregate reference; the expanded per-finger reference is for geometry checking only and must never replace the electrical model.

The complete layout must pass raw 100-device LVS (84 MOS fingers, four resistors, twelve contacts), deep and flat comparison, comparison to the original aggregate devices, all 560 main DRC categories and actual missing-HV-gate, open-input, missing-well-tap, missing-body-marker, body-short, width and off-grid fault controls. Simplification is disabled; combination is explicitly enabled only for the independent aggregate comparison. No blackboxes, implicit net connections or suppressed tap extraction are used. Imported port annotations are removed only after preserving all drawing geometry; parent labels define the actual six external ports.

After native physical gates pass, generate and validate the LEF, extract the complete interconnect, preserve actual junction geometry and finite-body modeling, and repeat the unchanged electrical/PVT/serial-tree checks before claiming integration. This run alone cannot establish a complete serializer, CDR, Gen3 x4 PHY, mainchip timing or production acceptance. All execution and evidence remain on GitHub-hosted runners.


The first assembly attempt 38867712321 stopped before generating a candidate: deleting imported pin-shape layers also removed the access geometry of a cached ptap PCell later reused by KLayout. Only imported port **text** is now removed; pin shapes and device-recognition labels are retained and included in the unchanged-geometry digest. This preserves access information without creating redundant parent port names. The failed generation log is retained; it was not a physical pass.

Polygon area and perimeter determine each finite-tap reference. The substrate tie receives the existing PDK `Substrate` plus `sub!` recognition convention used by native ptap1 cells, making its finite contact explicit instead of treating it as an ideal short. No implant, active, contact, gate or metal is changed. The imported geometry digest is rechecked after all assembly operations.

This is an explicitly recorded extraction-model refinement, not proof of substrate spreading or RF accuracy.
