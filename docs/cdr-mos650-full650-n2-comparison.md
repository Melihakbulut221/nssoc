## Complete large-waveform preservation

A complete native waveform can make the compressed output exceed the per-asset release size limit. Publication therefore preserves the same tar stream as ordered byte parts of at most1,800,000,000 bytes when needed. It independently rereads each part and the full joined stream against the original archive hash before removing only the redundant unsplit archive. archive-parts.json records the exact ordering, lengths, digests and original archive hash; complete-output-index.json still covers every original native member. Smaller archives retain their existing single-asset format.

Cloud source controls verify exact boundary sizes, byte reconstruction, reversed-part rejection and truncation rejection. These are transport controls only. They do not replace or qualify any native electrical result. Failed waveform results and all diagnostics are retained identically.
