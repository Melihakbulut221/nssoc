# Native HBT clock-buffer design candidate

Source branch [codex/cdr-cascode-clock-buffer-screen](https://github.com/Melihakbulut221/nssoc/tree/codex/cdr-cascode-clock-buffer-screen), commit87e2568c155bd4b818f626b3155132883e5fae4f, [native experiment43713082943](https://github.com/Melihakbulut221/nssoc/actions/runs/43713082943).

The existing actual650 loaded circuit remains rejected: original external clock source resistors see approximately26mA peak demand, sample/phase settling fails and two D-sampler HBTs violate minimumVCE. This experiment develops a new transistor topology rather than changing the original stimulus/source impedance or relaxing acceptance limits.

The candidate contains ten original IHP npn13G2 models: differential input pairNx12, two cascodesNx12, two crossed emitter followersNx12, diode-connected referenceNx1, differential tailNx12 and two follower tailsNx16. A0.5mA reference drives native current mirrors. Six ideal sizing resistors are initially50ohm collector pullups,430ohm pulldowns and100/355ohm cascode-bias divider. Cascodes are intended to share voltage headroom; crossed followers preserve clock polarity. These are proposed sizes, not a proven safe circuit.

The screen uses the unchanged original8GHz differential clock generator,2.5V supply ramp,10ohm external source resistors,34.25ns duration and0.3125ps maximum step. Three lumped loads100/250/500fF perleg are compared both direct and buffered. They are feasibility loads and DO NOT replace the actual650 nonlinear physical clock load. All ten HBT node voltages/model collector currents, native startup flags, complete raw traces and solver diagnostics are retained. Source current, clock crossings, output common mode and10/20/37.5ps signed margins are reported; these observation phases are not new fullPHY acceptance criteria.

The same pinned historical runtime is restored with every120 archive members authenticated and40 runtime/model members selected; its historical failure status is preserved. New native measurements run only onGitHub. Worker scripts/screen_cdr_clock_buffer.py and sizing netlist scripts/cdr_cascode_clock_buffer_candidate.inc. Derived/native artifacts cdr-clock-buffer-derived/native-RUN. No local CAD or native wave downloads.

**Limitations and mandatory next steps:** ideal resistors/capacitors and ideal substrate ground mean this is not a physical macro. It does not qualify current SOA, real rppd/contact/substrate models, PVT, full actual650 loaded behavior, layout/DRC/LVS/PEX, PLL/CDR closed loop, serialGen3x4 or chip integration. The worker always leaves accepted=false/fullPHY=false. Complete electrical failure must guide redesign; favorable standalone curves alone cannot promote the circuit. After a viable topology is measured, implement native passive/bias/contact geometry and test the entire original650 workload with all original gates and added-device coverage before any integration claim.
