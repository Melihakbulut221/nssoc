# v39: retimer pull-down candidate from measured loading

The four successful v36/v37 comparison jobs reproduce all original HBT and sampler results, including their rejection. With wider input/bias resistors, early AC positive follower mean collector current falls from1.411mA to0.642mA; BD falls from1.482mA to0.719mA. Minimum BD current falls from0.288mA to5.96uA. Current remains positive, so this is not a demonstrated cutoff event. The AC output differential range contracts from-234.7/+209.1mV to-159.3/+146.1mV while its base common mode is essentially unchanged. C master input minimum at the original edge falls36.28->24.00mV. Its37.5ps master output falls125.11->81.75mV. The median master/slave steering observations change only by hundredths of a picosecond. These findings support an input-loading/current hypothesis rather than an assumed clock shift.

Inspecting the exact original native composition identifies four existing emitter-to-AVSS pull-downs: XD0180/XD0184 on BD and XD0218/XD0219 on AC, all native rppd4um by2.25um. The candidate retains the v37 cdbias15 network and changes only these four lengths to1.8um or1.5um. A previous physical v31 change from4.5um to2.25um already addressed an earlier cutoff; that result is not evidence that the new dimensions pass.

Eight negative geometry/topology controls reject undeclared dimensions, missing/duplicate/wrong-node/wrong-model sinks. Binding follows the actual follower native identity, emitter cluster and AVSS cluster using native rppd_1/rppd_2 terminals; substrate is not mistaken for a current terminal. Exactly76 changed primitives relative to the original476-device contract must reverse to that identical contract. All17918 wire R and12850 wire C cards stay unchanged. The original clocks, source currents, full256bits/34.25ns/1104columns,150fF/50fF loads,100mV/37.5ps sampler and device/phase/current limits remain.

This is a bounded circuit hypothesis, not a complete repair claim. A still fails in the parent, and C minimum master-track VCE is close to the0.4V gate; stronger pull-down may trade differential swing against headroom and must be rejected if unsafe. No late failure is rounded away.
