Root cause from the preserved N1 waveform (run 41774032757): the samplers resolve every bit. The 1 um sampler-to-buffer rppd dividers act as 44-108 ps single poles, because the MIM bypass is far smaller than the buffer-input capacitance, so the XOR inputs arrive 1.1-1.6 UI late and 0.56 UI apart. The what-ifs reuse every extracted wire and change only the twelve divider resistors and six divider MIMs, so they are not a new layout. Details are in `docs/cdr-n1-phase-detector-trace.md` on `analysis/n1-wave-trace`.
