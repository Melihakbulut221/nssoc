## Fixed phase ownership

The unchanged `scripts/run_cloud_tx_mux4.py` `tree_plan(32)` and `scripts/tx_phase31_source_mapping.py` define 31 differential clocks, generated by 15 dividers plus one external root pair. Frequencies are one 4 GHz, two 2 GHz, four 1 GHz, eight 500 MHz and sixteen 250 MHz. Adjacent offsets are 125 ps; every original transition list and 256 UI centers must remain fixed. No post-measurement polarity, delay, origin or sample fitting is allowed.

For a divider whose parent halfperiod is H UIs and offset k, QP/QN owns child offset k+1 and the master owns offset (k+1-H) modulo 2H. Eleven master outputs require MN/MP and N/P internal master/slave presets; four require MP/MN and P/P. Every slave uses QP/QN. The source mapping controls proved only this abstract event ownership, not actual loaded phases.

## Loads that a real parent must include

The original TX source binds each clock to the `sp/sn` selector ports of exactly one mux. In `tx_mux2_hbt_cascade_v1.spice`, each leg drives two Nx=8 HBT bases: XSA_0/XSA_1 or XSB_0/XSB_1. The final `tx_mux54_passive_drive_v5.spice` has the same two Nx=8 base loads per leg (XD0046/47 for sp; XD0041/43 for sn). Thus the 31 selector pairs expose 124 actual HBT bases; replacing those loads with a nominal capacitance or resistance cannot establish acceptance.

Each of the fifteen nonleaf clock nodes also feeds one real divider input. The sixteen leaf clocks feed selectors only. Accordingly:

| Node class | Differential pairs | Required real receivers per pair |
|---|---:|---|
| Root, 4 GHz | 1 | Final mux selector plus root divider clock input |
| Generated nonleaf, 2 GHz through 500 MHz | 14 | Its mux selector plus one next divider clock input |
| Generated leaf, 250 MHz | 16 | Its mux selector |

The current high-input divider presents real XLSP/XLSN rppd W2/L3.6 access into its native level network; it is not a guessed input impedance. Its input must see the complete powered receiver and its downstream states. A parent-plus-two-children trial must therefore also include the parent's selector receivers and both child-output selector receivers when claiming the corresponding loaded stage. The old 55-device three-cell preparation includes actual child dividers but no selector interfaces and no reset; it cannot validate the new 241-device circuit.

## Reset distribution and first-fall release

The new source independently presets both master and slave using real data/hold selectors. Its ARM_P/ARM_N remain external fixture ports. Each of the fifteen cells adds a real XARM level input; a common reset driver must therefore drive fifteen actual differential receiving networks plus measured routes, with four hierarchy levels of clock-dependent release behavior.

Assertion must force the prescribed P/P or N/P pair under either external clock level while all downstream receiver loads remain powered. Deassertion must not itself toggle or swap phase ownership: each cell releases at its first actual parent falling edge after arm. Recovery/removal, setup to that first fall, selector propagation, feedback stability, voltage safety and loaded seed margin require finite-time measurements at every cell. The global arm distribution must be measured at every local ARM port; assume neither zero skew nor identical arrival.

Do not use .ic, nodeset, UIC, ideal internal reset drivers or fitted initial phase. The existing fixture's assertion at 12.03125 ns and release at 14.03125 ns test a single cell only. Full-tree reset timing needs an independently specified event contract that reaches all fifteen receivers before their prescribed release opportunities while retaining the original 31 phase/bit oracle.
