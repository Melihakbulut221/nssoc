# Registered RX reads and native well-spacing correction

The default receiver's live register D-input and output mux were checked against the SHA-256-verified flat reference with arbitrary memory bits, byte address, bank, prior register contents, staging byte and commit, restart and handshake inputs. The cursor cut relates the one-hot cursor to the binary index at the preceding position. It checks the active edge and all language-defined array addresses, including cross-bank reads. Optional read-ahead profiles, complete controller induction and external port equivalence require separate checks. Two parameter configurations passed and real packet address, DLLP address, stall, restart and commit mutants produced SAT counterexamples. The original flat fixture also passed, and both flat address mutants produced SAT counterexamples. [11 tests through make test](https://github.com/Melihakbulut221/nssoc/actions/runs/45739032984).

A second test exercises the entire default receiver with the repository's random stimulus (seed 1, 300,000 cycles). A separate scoreboard reads expected TLP or DLLP bytes directly from the live storage at every valid cycle, including stalls. The positive must satisfy the testbench's original output and coverage gates and the new TLP, DLLP and stall coverage gates. Both live address mutants must fail the storage comparison. [3 tests through make test](https://github.com/Melihakbulut221/nssoc/actions/runs/45739148703). This addresses the two failing parameter cases and replaces the two stale mutation cases from the 23-node current-source rerun. The remaining 19 failures have no passing rerun here.

For a separate diagnostic, the same full-receiver bench compared the pinned flat implementation with the live implementation. Only the reference module name and the bench's hierarchical handshake observer (equivalent external valid AND ready) were adapted. The original bench reported 298,314 mismatched cycles out of 300,000. Additional negedge counters found 71,379 valid differences and 46,931 byte differences across 75,660 cycles with both valid. The live storage scoreboard passing does not establish historical whole-controller equivalence.

On the 14-cell pre-diode checkpoint the native row filler installed 831,590 standard fill cells. Independent KLayout DRC went from 24,830 to 18,504. All 6,326 top-level NW.b markers disappeared. The other 672 category/cell groups and their counts matched exactly. Filled ODB SHA-256: 83372fdb1f4fc4b331a4e85e969d20a05a3be67a976aa2175acf3862c28eaffe.
