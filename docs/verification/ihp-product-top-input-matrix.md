# SG13G2 product-top input matrix

The interface implementation profile places `soc_top`. The separate `nssoc_chip` generator consumes the parameter-resolved core signature. Its checked-in contract describes 79 ports totalling 301 bits, including MBIST status before serialization. The selected shell uses 102 signal cells and four supply cells. These counts describe different boundaries. [RTL](../../hw/soc/rtl/soc_top.v) · [Interface profile](../../hw/soc/pnr/config-interfaces.json) · [Port contract](../../hw/soc/chip-io-contract.json) · [Shell and test protocol](../104-chip-io-and-test-access.md)

Treat every open row as a prerequisite for a product-top verdict. A prior result transfers only when its top, layout, schematic and applicable constraints match.

| Boundary | Available evidence | Input needed and responsibility |
|---|---|---|
| Digital I/O and test | GPIO, QSPI and MDIO have distinct input/output/enable paths. I²C drives low or releases. Four test pins serialize a 192-bit snapshot. | Internally regenerate against the exact mapped product profile, verify the real core with its shell, constrain the snapshot CDC and check reset recovery. Product test planning must supply fault targets, access and patterns for any scan/ATPG claim. |
| Core and I/O supplies | Shell binds VDD/VSS and IOVDD/IOVSS separately. The existing digital shell targets 3.3 V I/O. Native I/O behavioral models exercise wiring. | Product/board owner supplies rail ranges, sequencing, loads, package current and return paths. Internally size/distribute supply cells and check rail continuity, IR/EM and ESD network against selected library and package limits. PHY-specific rails depend on the selected macro. |
| Peripheral links | Ethernet exposes 8-bit RX/TX GMII and MDIO. SpaceWire exposes digital data/strobe and CAN exposes RX/TX. | Board owner selects external Ethernet PHY and SpaceWire/CAN transceivers, voltage compatibility, clocks, external loads and timing budgets. Internally verify the resulting pad and board-interface constraints. |
| PCIe | Conditional SOC_PCIE_PACKET exposes 8-bit packet data, framing, flow and link state. SOC_PCIE_ASYNC adds a digital clock. These ports are absent from the 79-port shell contract. | Product owner selects link configuration and on/off-die PHY boundary. For an on-die macro obtain authorized SG13G2 layout stream, LEF/obstructions, LVS schematic, functional and corner timing views, pin/rail map, clock/reset contract and electrical integration/ESD guidance from the IP source. For an off-die solution supply its actual digital interface and board timing. Internally reconcile PCS/controller responsibilities and verify transport and clock crossing. |
| Ring, package and die edge | The isolated ring passed 560 native main DRC categories on its recorded GDS. A prior core/ring assembly passed four abstract supply checks and reported seven native I/O master LVS failures. | Product/package owner selects bond or bump plan, pin map, die outline, usable edge, assembly tolerances and loading. Internally verify orientations, landings, rail continuity and seal enclosure against those inputs. Apply the supported seal to the complete die, then run native fill, density, antenna, DRC and LVS on that stream. |
| Manufacturing | Native simulation and open decks provide engineering evidence. | The applicable production rule set, qualification conditions and final acceptance require the process authority. |

The pinned I/O library has CDL, GDS, LEF, Liberty, SPICE and Verilog directories. Characterize each chosen master and verify cell names, pins, corner coverage and supply connectivity across the actual views.
