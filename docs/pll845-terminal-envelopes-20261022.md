# Complete physical-device terminal voltage coverage
The original all-column PLL reader preserves all5106 columns and gates the original full1us acquisition windows. It does not report all-device terminal voltage envelopes. This new independent cloud stage binds every845 device and all2737 physical terminals, plus four auxiliary body contacts, to the unchanged actual raw table and original immutable preparation.

Every terminal and every unordered pair of terminals gets signed minimum/maximum voltage and actual sample timestamps. The reducer reads bounded chunks, uses all samples, preserves the first extremum on ties, and never interpolates. Eleven corruption controls cover missing/duplicate bindings, native identity, swapped physical probes, false ground, units, missing contacts and nonfinite/nonmonotonic data at chunk boundaries. Known-value signed differences, exact ground and chunk-partition invariance are checked.

This first job checks the real bindings and the preserved46 complete startup rows. It retains the incomplete row bytes and cannot accept this prefix as a full1us capture. A future completed ordinary capture must pass the original table/row/finiteness/time/hash reader before this reducer is applied to all rows. No current density or device limits are inferred from terminal voltage, and no full-device or PHY safety is claimed. The active native controller, source hashes, original clocks, loads and acquisition gates remain untouched.
