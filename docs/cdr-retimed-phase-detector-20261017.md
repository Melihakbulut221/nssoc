# Native retimed phase detector integration

The actual half-cycle cascade run 39055313434, source 5a6bac4fd0cd7d4b889c91bdeb393c5568acfa2f, passed nominal/hot/cold and all three actual faults. Second-sampler minimum margins were 147.480/140.140/138.843 mV and clock-to-valid 24.53125/27.96875/22.65625 ps. Both samplers preserved the original bit identity, all 30 HBTs and two MIM devices met their voltage/current gates, 30 OFF flags were read back, startup OP was zero and diagnostics clean. Wrong-edge retiming produced 258 incorrect samples, reversed output 768, and stopped clock 381: each was detected. Complete reports are preserved in cdr-halfcycle-retime-pass-20261017.json. Earlier incomplete-capture results remain retained.

The next candidate integrates four real samplers and two physical-model comparators. At rising clock edge i, A is current center bit i; C samples the preceding A value, bit i-1. B samples serial data at the preceding falling edge; D retimes B onto the rising edge. X compares A with D, Y compares C with D. Every expected bit is derived from the original serial input and the declared clock/data offset, never from an actual intermediate waveform. This four-flop retiming arrangement provides a complete UI for both comparison outputs to settle.

The sampler-to-sampler converters retain the proven native geometry. A and C have separate native data buffers. D feeds one shared native select divider and two real select buffers, so the same sampler is not silently replaced by two ideal sources. Its two feedforward MIM capacitors are 4.8 um square to account for the additional buffer input load; all other conversion/driver geometry comes from the connected comparison candidate. This added fanout and A's extra retimer load require fresh native validation. Total: 114 HBT, 98 rppd, 10 MIM and 54 body contacts; both unchanged XOR extractions contribute 8040 wire resistors and 5282 capacitors. New inter-block physical parasitics are not yet present.

Eleven Actions cases test +/-0.15 UI data offsets at nominal/hot/cold supply/resistor/cap conditions, constant zero/one, swapped comparison outputs, actual wrong-edge D, and a stopped clock. All use HBTtyp models; this is not complete process/mismatch qualification. Data slope remains 5 ps, clock slope 5 ps, external clock 8 GHz, each source 10 ohms. All eight sampler outputs retain 150 fF and four XOR outputs 50 fF. Six external 500 uA sampler/XOR references and four 1 mA buffer references remain explicit bench boundaries.

Before seeing results, gates are fixed: all four samplers preserve original bit identity at 0.3/0.6/0.9 UI with 100 mV and 37.5 ps valid bounds. Both comparators preserve their original expected XOR bits at 0.6/0.75/0.9 UI with 100 mV and 75 ps bounds. Signed average X-Y over START+8UI through START+255UI must exceed 30 mV for known early/late offsets, and stay within 10 mV for no transitions. No fitted latency or sample-phase adjustment. All 114 HBTs retain VCE 0.4–1.6 V (upper absolute over startup), |VBE|<=1 V and |Ic|/emitter<3 mA; all 12 sampler/buffer tails remain >=0.5 mA, all MIM terminal voltages <=1.6 V. Actual faults must fail the original oracle.

The source hypothesis follows the consecutive-sample phase relationship discussed in Lee, Kundert and Razavi, JSSC 2004, https://kenkundert.com/docs/jssc04-09.pdf . That paper explicitly distinguishes transistor-level PD/fanout characterization from the following low-speed V/I converter. It is architecture guidance, not evidence that this circuit or a closed loop works. The V/I path, recovered clock, acquisition, frequency offset, missing-transition behavior over long runs, jitter/BER, full process qualification, physical extraction and x4/mainchip integration remain required.

## Native binding correction

Initial run 39056285138 stopped before simulation: the generic binder accepted only Nx, but the hash-pinned physical XOR model also retains explicit WE=0.07um and LE=0.9um emitter dimensions. Those parameters were already present in the previously verified extracted model. The corrected binder requires exactly Nx/WE/LE for physical XOR HBTs, with the exact dimensions, and exactly Nx for schematic sampler/buffer HBTs. Five real parameter-list mutations reject wrong width, wrong length, absent area, unknown parameters and duplicate names. No parameter is ignored or stripped; native circuit, waveform sources and acceptance gates are unchanged. The first failed report is retained in cdr-retimed-pd-binding-error-20261017.json. All eleven cases must rerun before electrical conclusions.
